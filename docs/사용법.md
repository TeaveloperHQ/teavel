# Teavel 쓰는 법

컴퓨터 세팅을 대신 해 주는 프로그램입니다.
**컴퓨터를 잘 몰라도 됩니다.** 물어보는 대로 답하시면 됩니다.

---

## 1. 받고 열기

포털에서 받으면 **파일 하나**가 `다운로드` 폴더에 들어갑니다.

이름에 판 번호가 붙어 `teavel-0.1.0.exe` 처럼 올 수 있습니다. 맞게 받으신 겁니다.

**그 파일을 두 번 누르세요.** 그러면 까만 창이 열립니다.

### "Windows에서 PC를 보호했습니다" 가 나오면

파란 창이 뜨면서 실행을 막을 수 있습니다. **고장이 아닙니다.**
Windows 는 처음 보는 프로그램을 일단 막습니다.

```
  [추가 정보]  를 누르시고
  아래에 나오는  [실행]  을 누르세요
```

한 번만 하면 다음부터는 안 물어봅니다.

### 열리면 이런 화면입니다

```
    ▲ Teavel   선생님 컴퓨터를 대신 세팅해 드립니다

      처음이시면  점검  을 쳐 보세요.
      무엇을 칠 수 있는지 모르시면  도움말

  하고 싶은 일을 그냥 적으셔도 됩니다.  예: 엑셀 다 합쳐줘

  · 아직 PowerShell 어디서나 실행되도록 등록돼 있지 않습니다.
        등록하면 다음부터 아무 폴더에서나 teavel 만 치면 됩니다.
        지금 등록할까요? [Y/n]
```

**그냥 Enter 를 누르세요.** 그러면 두 가지가 됩니다.

- 다음부터는 아무 폴더에서나 `teavel` 만 치면 됩니다
- **폴더에 오른쪽 단추** → `여기서 Teavel 열기`

그다음 **말을 알아듣는 언어 모델을 받겠느냐**고 묻습니다. **여기서도 그냥 Enter** 를 누르세요.
1GB 쯤 되고 몇 분 걸리는데, 한 번만 받으면 됩니다. 이게 있어야 말투가 달라도 알아듣습니다.

> **다운로드 폴더에 두신 채로 등록하면** 나중에 그 폴더를 비울 때 Teavel 이 사라집니다.
> Teavel 이 그때 알려 드립니다. 다른 폴더로 옮기신 뒤 `설치` 를 한 번 더 하시면 됩니다.
>
> 관리자 권한은 필요 없습니다. 나중에 `제거` 라고 치면 되돌립니다(프로그램은 안 지워집니다).
> Windows 11 에서는 오른쪽 단추를 누른 뒤 **[추가 옵션 표시]** 안에 있습니다.

### 창이 열린 뒤에는

`>` 다음에 하고 싶은 것을 치시면 됩니다. **무엇을 칠 수 있는지 모르시겠으면 `도움말`** 이라고 치세요.

```
> 도움말
```

## 2. 제일 먼저 할 것

열린 창의 `>` 다음에 이렇게 칩니다.

```
> 점검
```

지금 무엇이 안 돼 있는지 알려 줍니다.

```
① 이 컴퓨터와 계정 — 먼저 정해 둘 것
  ! Windows 에 학교 계정 잇기 — 연결돼 있지 않습니다.
        ↑ 이것부터 하시면 아래 것들이 대부분 함께 해결됩니다.
  ! OneDrive 로그인 — 로그인돼 있지 않습니다.

② 자료 지키기 — 잃어버리지 않게
  ! 바탕 화면·문서·사진 백업 — 3개 폴더가 백업되지 않고 있습니다.
```

그다음 이렇게 칩니다.

```
> 고침
```

**하나씩 물어보면서 손봅니다.** 그냥 Enter 를 누르면 "네" 입니다.

비밀번호가 필요한 일은 대신 해 드릴 수 없습니다.
그때는 **설정 화면을 열어 드리고 어디를 누르면 되는지** 알려 드립니다.

## 3. 말로 시키기

`>` 다음에 하고 싶은 일을 그냥 적으시면 됩니다.

```
> 엑셀 다 합쳐줘
```

**폴더에서 오른쪽 단추로 여시면 훨씬 편합니다.** 폴더 경로를 안 쳐도 되거든요.

```
> 엑셀 다 합쳐줘

  엑셀 파일 여러 개를 하나로 합치기
      폴더 (그냥 Enter 면 현재 폴더: 2반 수행평가):     ← 그냥 Enter
      저장할 파일: 통합.xlsx
```

### 이런 것들을 할 수 있습니다

| 이렇게 말씀하시면 | 이런 일을 합니다 |
|---|---|
| 엑셀 다 합쳐줘 | 폴더 안 엑셀들을 하나로 이어 붙입니다 |
| 반별로 나눠줘 | 한 파일을 반(열 값)마다 갈라 저장합니다 |
| 점수 통계 내줘 | 평균·최고·최저·표준편차를 냅니다 |
| 파일 이름 바꿔줘 | 여러 파일 이름을 한꺼번에 고칩니다 |
| 학번별로 폴더 나눠줘 | 파일 이름의 학번을 보고 폴더로 나눕니다 |
| 안 낸 사람 찾아줘 | 명단과 견줘 미제출자를 찾습니다 |
| 압축 다 풀어줘 | 폴더 안 압축 파일을 전부 풉니다 |
| 개인별 메일 만들어줘 | 명단으로 한 사람씩 메일 초안을 만듭니다 |
| 첨부 파일 모아줘 | 받은 메일의 첨부를 한 폴더에 모읍니다 |
| 명단으로 문서 만들어줘 | 워드 서식에 명단을 채워 사람 수만큼 만듭니다 |
| PDF 로 바꿔줘 | 워드 문서들을 한꺼번에 PDF 로 만듭니다 |
| 기본 프린터 3층복도로 해줘 | 기본 프린터를 정합니다 |

**목록을 보고 싶으시면** `목록` 이라고 치세요.

### 언어 모델을 아직 안 받으셨다면

처음에 "지금 받을까요?" 에서 아니요를 누르셨어도 언제든 받으실 수 있습니다.

```
> 모델
```

안 받아도 쓸 수 있지만, 받으면 말투가 달라도 알아듣습니다.

```
받기 전    "엑셀 합치기"  → 됨      "엑셀들 좀 묶어줘"  → 잘 못 알아들음
받은 뒤    둘 다 됨
```

## 4. 막혔을 때

**무슨 말인지 못 알아들으면** — 짧고 쉽게 다시 말씀해 보세요. "엑셀 합쳐" 처럼요.
그래도 안 되면 `목록` 에서 골라 쓰시면 됩니다.

**여러 개 중에 고르라고 하면** — 번호를 치시면 됩니다. 아니면 그냥 Enter 로 취소됩니다.

**그만두고 싶으면** — `Ctrl` 키를 누른 채 `C` 를 누르세요.

**Teavel 자체가 이상하면**

```
> 자가점검
```

프로그램이 온전한지 스스로 확인합니다.

---

## 5. 조심하실 것

- **원본 파일은 건드리지 않습니다.** 합치기·나누기는 새 파일을 만듭니다.
- **덮어쓰지 않습니다.** 같은 이름이 있으면 건너뛰고 그렇게 알려 드립니다.
- 엑셀·워드 작업 중에는 **그 프로그램 창을 닫지 마세요.**
- 인터넷으로 아무것도 보내지 않습니다. **학생 자료가 이 컴퓨터 밖으로 나가지 않습니다.**
  (언어 모델을 받을 때만 인터넷을 씁니다)

## 학교 전체를 맡고 계시다면

학교의 Teams·그룹을 만들고 정리하는 기능이 따로 있습니다.
**학교 M365 관리자(전역 관리자)만** 쓸 수 있습니다.

```
> m365
```

명단 파일만 있으면 반 팀을 만들고 학생을 넣고 담임까지 정합니다.
엑셀·한셀·한글 아무 모양이나 됩니다 — **양식을 맞추지 않으셔도 됩니다.**

자세한 것은 [학교 M365 구성](m365.md) 을 보세요.

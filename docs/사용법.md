# Teavel 쓰는 법

컴퓨터 세팅을 대신 해 주는 프로그램입니다.
**컴퓨터를 잘 몰라도 됩니다.** 물어보는 대로 답하시면 됩니다.

---

## 1. 받고 열기

포털에서 받으면 **파일 하나**가 `다운로드` 폴더에 들어갑니다.

이름에 판 번호가 붙어 `teavel-0.1.0.exe` 처럼 올 수 있습니다. 맞게 받으신 겁니다.

**그 파일을 두 번 누르세요.** 그러면 까만 창이 열립니다.

### "Windows에서 PC를 보호했습니다" 가 나오면

파란 창이 뜨면서 실행을 막을 수 있습니다. **고장이 아닙니다.**
Windows 는 처음 보는 프로그램을 일단 막습니다.

```
  [추가 정보]  를 누르시고
  아래에 나오는  [실행]  을 누르세요
```

한 번만 하면 다음부터는 안 물어봅니다.

### 열리면 이런 화면입니다

```
    ▲ Teavel   선생님 컴퓨터를 대신 세팅해 드립니다

      처음이시면  점검  을 쳐 보세요.
      무엇을 칠 수 있는지 모르시면  도움말

  하고 싶은 일을 그냥 적으셔도 됩니다.  예: 엑셀 다 합쳐줘

  · 아직 PowerShell 어디서나 실행되도록 등록돼 있지 않습니다.
        등록하면 다음부터 아무 폴더에서나 teavel 만 치면 됩니다.
        지금 등록할까요? [Y/n]
```

**그냥 Enter 를 누르세요.** 그러면 두 가지가 됩니다.

- 다음부터는 아무 폴더에서나 `teavel` 만 치면 됩니다
- **폴더에 오른쪽 단추** → `여기서 Teavel 열기`

그다음 **말을 알아듣는 데 쓸 것을 받겠느냐**고 묻습니다. **여기서도 그냥 Enter** 를 누르세요.
1GB 쯤 되고 몇 분 걸리는데, 한 번만 받으면 됩니다. 이게 있어야 말투가 달라도 알아듣습니다.

> 두 가지를 차례로 받습니다. 먼저 **말을 쪼개는 것**(작고 빠릅니다), 그다음 **언어 모델**입니다.
> 중간에 끊겨도 괜찮습니다 — 다시 `모델` 이라고 치면 받던 곳부터 이어서 받습니다.

> **다운로드 폴더에 두신 채로 등록하면** 나중에 그 폴더를 비울 때 Teavel 이 사라집니다.
> Teavel 이 그때 알려 드립니다. 다른 폴더로 옮기신 뒤 `설치` 를 한 번 더 하시면 됩니다.
>
> 관리자 권한은 필요 없습니다. 나중에 `등록해제` 라고 치면 되돌립니다(프로그램은 안 지워집니다).
> Windows 11 에서는 오른쪽 단추를 누른 뒤 **[추가 옵션 표시]** 안에 있습니다.

### 학교에서 컴퓨터를 처음 받으셨다면

`계정` 이라고 치세요. 이것 하나가 나머지의 대부분입니다.

할 일이 열 가지쯤 보이지만, 실제로는 **학교 계정 하나를 Windows 에 이어 두면**
Edge·원드라이브·오피스·아웃룩·팀즈가 그 계정을 물어다 씁니다. 앱마다 따로 로그인하면
같은 비밀번호를 다섯 번 넣게 되고, 한 번 틀리면 무엇이 됐는지 알 수 없게 됩니다.

그래서 순서대로 갑니다.

1. 지금 무엇이 이어져 있고 무엇이 안 이어져 있는지 보여 드립니다
2. Windows 에 학교 계정을 잇습니다 (이 컴퓨터가 학교 것인지 개인 것인지에 따라 안내가 다릅니다)
3. 그러고도 안 따라온 앱만 하나씩 엽니다

**비밀번호는 대신 넣어 드릴 수 없습니다.** 대신할 수 있으면 비밀번호가 아니게 되니까요.
그 한 단계만 선생님이 하시면 되고, 나머지는 Teavel 이 합니다.

- 설정 화면을 정확히 띄웁니다
- **끝나는 것을 지켜보다 알아서 다음으로 넘어갑니다** — 언제 Enter 를 눌러야 하나
  고민하실 필요가 없습니다 (기다리기 싫으시면 Enter 를 누르셔도 됩니다)
- 계정이 붙고 나면 **원드라이브가 스스로 로그인하게** 해 드립니다. 누르실 것이 없습니다.
  바탕 화면·문서·사진 백업도 함께 켭니다.

원드라이브 자동 로그인은 컴퓨터 전체 설정이라 **관리자 권한이 필요하고, 반드시 여쭤본 뒤에
켭니다.** 켠 뒤에 마음이 바뀌시면 `계정` 을 다시 실행하시면 끌지 여쭤봅니다.

**원드라이브는 따로 봅니다.** 로그인은 쉬운데 "그래서 내 파일이 어디 있는 건데" 가
어렵기 때문입니다. 그래서 이런 것을 보여 드립니다.

- 원드라이브 폴더가 어디인지 — 여기 넣은 것만 백업됩니다
- 바탕 화면·문서·사진이 백업되고 있는지
- 폴더 안에 무엇이 있고, 그중 어느 것이 '온라인에만' 있는지
  (자리를 차지하지 않고 열면 그때 내려받는 것입니다. 지워진 게 아닙니다)
- 팀즈에 올린 파일이 왜 원드라이브에 안 보이는지 — 폴더 '옆' 에 따로 붙습니다

어떤 폴더를 이 컴퓨터에 내려둘지 고르는 것은 원드라이브가 직접 물어봐야 하는 일이라
대신 눌러 드릴 수는 없습니다. 대신 그 창을 띄우고 어디를 누르면 되는지 짚어 드립니다.

### 지우고 싶으실 때

`삭제` 라고 치시면 됩니다. 무엇을 지울지 먼저 보여 드리고, **내려받아 둔 것(언어 모델·형태소
분석기, 1GB 남짓)은 지울지 따로 여쭤봅니다** — 자리만 옮기시는 거라면 남겨 두는 편이 낫습니다.

`설치` 를 하셨으면 **Windows 설정 &gt; 앱 &gt; 설치된 앱** 목록에도 Teavel 이 있습니다.
거기서 [제거] 를 누르셔도 같은 일이 일어납니다.

### 창이 열린 뒤에는

`>` 다음에 하고 싶은 것을 치시면 됩니다. **무엇을 칠 수 있는지 모르시겠으면 `도움말`** 이라고 치세요.

```
> 도움말
```

## 2. 제일 먼저 할 것

열린 창의 `>` 다음에 이렇게 칩니다.

```
> 점검
```

지금 무엇이 안 돼 있는지 알려 줍니다.

```
① Windows 부터 — 여기가 묵으면 아래가 다 막힙니다
  ! Windows 최신 상태 — 지원이 끝난 판입니다 — 22H2

② 이 컴퓨터와 계정 — 먼저 정해 둘 것
  ! Windows 에 학교 계정 잇기 — 연결돼 있지 않습니다.
        ↑ 이것부터 하시면 아래 것들이 대부분 함께 해결됩니다.
  ! OneDrive 로그인 — 로그인돼 있지 않습니다.

③ 자료 지키기 — 잃어버리지 않게
  ! 바탕 화면·문서·사진 백업 — 3개 폴더가 백업되지 않고 있습니다.
```

그다음 이렇게 칩니다.

```
> 고침
```

**하나씩 물어보면서 손봅니다.** 그냥 Enter 를 누르면 "네" 입니다.

비밀번호가 필요한 일은 대신 해 드릴 수 없습니다.
그때는 **설정 화면을 열어 드리고 어디를 누르면 되는지** 알려 드립니다.

## 3. 말로 시키기

`>` 다음에 하고 싶은 일을 그냥 적으시면 됩니다.

```
> 엑셀 다 합쳐줘
```

**폴더에서 오른쪽 단추로 여시면 훨씬 편합니다.** 폴더 경로를 안 쳐도 되거든요.

```
> 엑셀 다 합쳐줘

  엑셀 파일 여러 개를 하나로 합치기
      폴더 (그냥 Enter 면 현재 폴더: 2반 수행평가):     ← 그냥 Enter
      저장할 파일: 통합.xlsx
```

### 그냥 말을 걸으셔도 됩니다

무엇을 쳐야 할지 모르시겠으면 아무 말이나 하셔도 됩니다.

```
> 안녕 대화좀 해보자

  안녕하세요, 선생님. 편하게 말씀하셔도 됩니다.
      하시려는 일을 그냥 적어 주시면 그대로 해 드립니다.
```

```
> 뭘 해야 할지 모르겠어

  그러실 때는 '점검' 부터 해 보시면 좋습니다.
      지금 이 컴퓨터에 안 돼 있는 것을 짚어 드립니다.
      지금 해 볼까요? [Y/n]
```

**할 수 없는 일은 할 수 없다고 말씀드립니다.** 날씨나 뉴스 같은 것은 답해 드리지 못합니다.
그럴 때는 대신 해 드릴 수 있는 것을 보여 드립니다.

### 이런 것들을 할 수 있습니다

| 이렇게 말씀하시면 | 이런 일을 합니다 |
|---|---|
| 엑셀 다 합쳐줘 | 폴더 안 엑셀들을 하나로 이어 붙입니다 |
| 반별로 나눠줘 | 한 파일을 반(열 값)마다 갈라 저장합니다 |
| 점수 통계 내줘 | 평균·최고·최저·표준편차를 냅니다 |
| 파일 이름 바꿔줘 | 여러 파일 이름을 한꺼번에 고칩니다 |
| 학번별로 폴더 나눠줘 | 파일 이름의 학번을 보고 폴더로 나눕니다 |
| 안 낸 사람 찾아줘 | 명단과 견줘 미제출자를 찾습니다 |
| 압축 다 풀어줘 | 폴더 안 압축 파일을 전부 풉니다 |
| 개인별 메일 만들어줘 | 명단으로 한 사람씩 메일 초안을 만듭니다 |
| 첨부 파일 모아줘 | 받은 메일의 첨부를 한 폴더에 모읍니다 |
| 명단으로 문서 만들어줘 | 워드 서식에 명단을 채워 사람 수만큼 만듭니다 |
| PDF 로 바꿔줘 | 워드 문서들을 한꺼번에 PDF 로 만듭니다 |
| 컴퓨터 이름 뭐야 | 이 컴퓨터의 이름과 바꿔야 할지 알려줍니다 |

**목록을 보고 싶으시면** `목록` 이라고 치세요.

### 아직 안 받으셨다면

처음에 "지금 받을까요?" 에서 아니요를 누르셨어도 언제든 받으실 수 있습니다.

```
> 모델
```

안 받아도 쓸 수 있지만, 받으면 말투가 달라도 알아듣습니다.

```
받기 전    "엑셀 합치기"  → 됨      "엑셀들 좀 묶어줘"  → 잘 못 알아들음
받은 뒤    둘 다 됨
```

**받는 데 인터넷이 느려서 오래 걸린다면** 그냥 두셔도 됩니다. 안 받은 채로도 목록에서
골라 쓰실 수 있고, 나중에 언제든 `모델` 이라고 치시면 됩니다.

## 4. 막혔을 때

**"무슨 말씀이신지 잘 모르겠습니다"** 가 나오면 — 너무 짧게 치셨을 때 나옵니다.
`1` 이나 `ㅋㅋ` 처럼요. 하시려는 일을 낱말로 적어 주시면 됩니다.

**무슨 말인지 못 알아들으면** — 짧고 쉽게 다시 말씀해 보세요. "엑셀 합쳐" 처럼요.
그래도 안 되면 `목록` 에서 골라 쓰시면 됩니다.

**여러 개를 보여 주면서 고르라고 해도 정상입니다.** 확실하지 않을 때 넘겨짚어 엉뚱한 것을
실행하느니 여쭤보게 만들었습니다. 번호만 누르시면 됩니다.

**여러 개 중에 고르라고 하면** — 번호를 치시면 됩니다. 아니면 그냥 Enter 로 취소됩니다.

**그만두고 싶으면** — `Ctrl` 키를 누른 채 `C` 를 누르세요.

**Teavel 자체가 이상하면**

```
> 자가점검
```

프로그램이 온전한지 스스로 확인합니다.

---

## 5. 조심하실 것

- **원본 파일은 건드리지 않습니다.** 합치기·나누기는 새 파일을 만듭니다.
- **덮어쓰지 않습니다.** 같은 이름이 있으면 건너뛰고 그렇게 알려 드립니다.
- 엑셀·워드 작업 중에는 **그 프로그램 창을 닫지 마세요.**
- 인터넷으로 아무것도 보내지 않습니다. **학생 자료가 이 컴퓨터 밖으로 나가지 않습니다.**
  (언어 모델을 받을 때만 인터넷을 씁니다)

---

## 학교 전체를 맡고 계시다면

학교의 Teams·그룹을 만들고 정리하는 기능이 따로 있습니다.
**학교 M365 관리자(전역 관리자)만** 쓸 수 있습니다.

```
> m365
```

**인터넷 창에 관리 화면이 열립니다.** 왼쪽에서 할 일을 고르고 눌러서 하시면 됩니다 —
단추를 누르기 전까지는 아무 일도 일어나지 않으니 편히 둘러보셔도 됩니다.

명단 파일만 있으면 반 팀을 만들고 학생을 넣고 담임까지 정합니다.
엑셀·한셀·한글 아무 모양이나 됩니다 — **양식을 맞추지 않으셔도 됩니다.**

자세한 것은 [학교 M365 구성](m365.md) 을 보세요.
